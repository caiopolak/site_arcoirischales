# Arco-Íris Chalés — Maresias

Site institucional para apresentar os chalés e a pousada Arco-Íris, em Maresias, e facilitar o contato de pessoas interessadas.

🌐 **Site:** https://caiopolak.github.io/site_arcoirischales/

## Sobre o projeto

Este repositório contém a implementação web do site: estrutura semântica em HTML, estilos responsivos em CSS e interações em JavaScript. A experiência foi preparada para apresentar o empreendimento e suas informações de forma acessível em dispositivos móveis e desktop.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Executar localmente

Abra `index.html` em um navegador ou use uma extensão de servidor local para testar as páginas. A publicação atual é feita pelo GitHub Pages.
